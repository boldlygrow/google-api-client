# 4.0

* **Release Date:** 2024-02-28

## Overview

This release is a re-write and consolidation of the `glamstack/google-auth-client`, `glamstack/google-workspace-sdk`, and `glamstack/google-cloud-sdk` packages that focuses on developer experience optimization and lessons learned. This is not backwards compatible and should be treated as a new package that requires reimplementation of any API calls that used those previous packages.

See the `README.md` to learn about the capabilities, features, and usage instructions.
